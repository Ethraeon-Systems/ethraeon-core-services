# ETHRAEON Core Services

Public, open-source service layer for ETHRAEON governance-adjacent runtime components that are safe for public distribution.

## Purpose
- Host reusable API and worker service code intended for public collaboration
- Keep constitutional runtime internals and protected IP out of public scope
- Provide integration surfaces for web, mobile, SDK, and automation consumers

## Public Scope (Non-IP)
- API contracts and schemas
- SDK-facing adapters
- Dev/test harnesses for public demos
- Worker orchestration scaffolds (public-safe)
- CI/CD and observability templates

## Not Included
- Protected constitutional internals
- Private operational evidence
- Restricted patent claim internals

## Integration Targets
- Web: browser clients and edge runtimes
- Mobile: iOS and Android clients via API layer
- Desktop/OS: macOS, Windows, Linux clients via HTTP/gRPC adapters
- SaaS: tenant-aware API patterns and billing-safe interfaces
